HOW 3 · LLM

AI 생성

AI 비서 — 이렇게 만들었습니다

1 · 질문

운영자의 질문과 화면의 실제 수치(JSON)

2 · 분류

정해진 답(요금표·용어)은 데이터에서, 명령은 적용 카드로

3 · 로컬 LLM

파인튜닝한 Qwen3-8B(v2.2), 이 PC에서 무료로

4 · 검증

답변 속 숫자·의미를 데이터와 대조

5 · Claude

관리자 키에서만 (공개 데모는 로컬 모델만)

6 · 승인

사람이 눌러야만 적용됩니다

왜 이렇게 만들었나

  • 제어는 에이전트, AI는 설명·제안 — 직접 제어는 ‘과도한 권한’(OWASP LLM06)
  • 답이 정해진 질문은 모델 없이 데이터로 — 예상 질문 66개 점검에서 오답 17 → 0, 점수 41.5 → 62점 (분류·조회·출력 점검, 모델 v2.1 그대로 · Claude 채점)
  • 숫자·의미를 데이터와 대조 — ‘상한 940 kW’, ‘여유를 초과로’ 같은 오답에 경고
  • 모든 답변에 ‘AI 생성’ 표시 — 인공지능기본법 제31조

07 · 운영 PC 실측(예상 질문 66개): 모델이 답한 47개 중앙값 1.9초·0원, 19개는 모델 없이 · Claude(관리자 키) 9–13초·약 $0.037

(40초) AI 비서는 이렇게 만들었습니다. 운영자가 물으면 화면의 실제 수치가 함께 갑니다. 먼저 질문을 나눠서, 요금 시간표나 용어처럼 답이 정해진 질문은 모델 없이 데이터에서 바로 답하고, ‘빈 방 조명 꺼 줘’처럼 분명한 명령은 바로 적용 카드로 만듭니다. 해석이 필요한 질문만 이 PC에서 도는, 저희가 파인튜닝한 Qwen3-8B에게 보냅니다. 오른쪽 화면처럼 답마다 데이터 조회인지 모델 답인지 표시됩니다. 답 속 숫자와 의미는 실제 데이터와 대조해 어긋나면 경고를 붙이고, Claude는 운영자의 관리자 키에서만 씁니다. 제안은 사람이 눌러야만 적용됩니다. 왜 이렇게 했냐면, 첫째 LLM에 제어를 맡기면 OWASP가 말하는 과도한 권한 문제가 생깁니다. 둘째, 방문자가 칠 만한 질문 66개로 점검해 보니 모델이 배운 틀 밖의 질문을 가장 가까운 틀로 답해서, ‘제일 싼 시간’을 물으면 지금이 제일 싸다고 하는 식의 오답이 17개였습니다. 질문 분류와 데이터 조회, 출력 점검을 더하자 모델을 바꾸지 않고도 오답이 0개가 됐습니다. 이 채점은 개발을 도운 Claude가 답을 모두 읽고 한 것이고, 항목별 근거를 공개해 두었습니다. 셋째, 모든 답변에는 인공지능기본법 제31조에 맞춰 AI 생성 표시를 붙입니다.
