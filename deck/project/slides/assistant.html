3 · 로컬 LLM

Qwen3-8B, 이 PC에서 무료로

4 · 검증

5 · Claude

검증 실패·제어 제안만 Opus 5.5로

6 · 승인

사람이 눌러야만 적용됩니다

왜 이렇게 만들었나

  • 제어는 에이전트, AI는 설명·제안 — 직접 제어는 ‘과도한 권한’(OWASP LLM06)
  • 숫자·의미를 데이터와 대조 — 실측 중 ‘상한 940 kW’, ‘여유를 초과로’ 같은 오답을 잡아 Claude로 넘겼습니다
  • 모든 답변에 ‘AI 생성’ 표시 — 인공지능기본법 제31조

07 · 실측: 로컬 Qwen3-8B 질문당 3–8초·0원, Claude Opus 5.5 질문당 9–13초·약 $0.037

(50초) AI 비서는 저희가 이렇게 만들었습니다. 운영자가 질문하면, 화면에 있는 실제 수치를 JSON으로 묶어 먼저 이 PC에서 도는 로컬 모델 Qwen3-8B에게 보냅니다. 무료이고 데이터가 밖으로 나가지 않습니다. 답이 오면 답변 속 숫자와 의미를 실제 데이터와 대조합니다. 검증에 실패하거나 제어 제안처럼 중요한 작업만 Claude Opus 5.5로 넘깁니다. 그리고 제안은 사람이 버튼을 눌러야만 적용됩니다. 왜 이렇게 했냐면, 첫째 LLM에 제어를 직접 맡기면 OWASP가 말하는 과도한 권한 문제가 생기고, 둘째 LLM은 숫자를 지어내기 때문입니다. 실제로 측정하다가 로컬 모델이 피크 상한을 940 kW라고 하거나, 여유를 초과라고 거꾸로 말하는 오답을 발견했고, 그래서 검증을 강화해 이런 답은 Claude로 넘어가게 했습니다. 오른쪽 화면이 실제로 넘어간 기록입니다. 마지막으로 모든 답변에는 인공지능기본법 제31조에 맞춰 AI 생성 표시를 붙입니다.
