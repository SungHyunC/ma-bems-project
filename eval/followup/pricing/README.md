# 시간대별 전력 단가 격차 민감도

2025년 7월 세종 기상과 프로젝트의 계절·시간대별 요금 입력 [`kepco_2025_07.json`](../../data/kepco_2025_07.json)을 사용했다. 경부하 단가 87.3원/kWh를 고정했고, 이 단가와 다른 시간대의 차이에 0.8배, 1.0배, 1.2배를 적용했다. 일반 중간부하 단가는 129.62, 140.20, 150.78원/kWh, 최대부하는 195.30, 222.30, 249.30원/kWh였다. 수요반응 단가는 시뮬레이터의 기존 규칙에 따라 입력 최고 단가의 3배로 설정했다.

코디네이터 v2와 기존 연간 실험의 전기 난방 설정(`heat=1`)을 사용했다. 두 제어기에 같은 입력을 주고 1분 간격으로 31일간 제어를 다시 실행했다. 7월 2~31일 전력량요금 합계에서 `100 × (BMS 요금 − MA-BEMS 요금) / BMS 요금`으로 절감률을 구했다. 집계는 전력량요금 기준이다. 기본요금, 세금 및 조정요금은 제외했다.

| 경부하 대비 단가 격차 | 기본 BMS 대비 절감 | 숙련 BMS 대비 절감 |
| --- | ---: | ---: |
| 20% 축소 | 12.78% | 5.29% |
| 원 요금표 | 13.32% | 5.30% |
| 20% 확대 | 13.78% | 5.31% |

원 요금표에서 저장소의 `build/results/fb/kc_07_basic.json`, `kc_07_expert.json`을 재현했다. 일별 전력량요금 차이는 0.000001원 미만이었고 15분 수전 기록은 일치했다. 세 배율의 15분 수전량, 일별 에너지·피크·쾌적률과 한도 초과 시간은 같았다. 이 결과는 전력량요금 시나리오의 효과를 보여 준다. 제품 가격이나 구매 의향은 별도의 조사가 필요하다.

## 재현

저장소 최상위 디렉터리에서 Node.js 20 이상으로 실행한다.

```bash
node eval/followup/pricing/run.cjs > /tmp/ma-bems-tariff.json
```

[`summary.json`](summary.json)은 비교별 전력량요금, 절감률, 15분 최대 수전 및 쾌적률을 담는다. 저장소의 기존 결과 재현과 세 배율의 물리 지표 일치는 실행 중 자동으로 확인한다.
