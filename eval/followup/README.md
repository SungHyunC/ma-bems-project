각 폴더의 README에 실행 방법과 결과표가 있습니다. 요금·제어 기능·재실 일정 실험은 [공용 실행기](sim.cjs)로 `index.html`의 시뮬레이터와 `eval/exp.mjs`의 평가 루프를 Node.js에서 실행합니다. EnergyPlus 비교는 별도의 단일 실 IDF와 Python 실행 스크립트를 사용합니다.

실제 건물 적용 효과는 HVAC와 전력량을 계량해 검증해야 합니다. 최적 에이전트 수를 정하려면 제어 기능을 유지하면서 에이전트를 묶거나 나눈 구성을 비교해야 합니다.
